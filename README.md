# braille ⠃⠗⠁⠊⠇⠇⠑

终端里的一级英文盲文翻译器：文本 ↔ Unicode 盲文点字（U+2800 区）。

## 用法

```bash
python -m braille "hello world"      # 文本 -> 盲文
python -m braille --decode "⠓⠑⠇⠇⠕"  # 盲文 -> 文本
echo "abc" | python -m braille        # 管道输入
```

编码规则（一级盲文）：

- 字母 a–z → 对应点字，如 `abc` → `⠁⠃⠉`
- 大写字母前加大写符 ⠠，如 `Hi` → `⠠⠓⠊`
- 数字前加数字符 ⠼，数字用 a–j 表示，如 `2026` → `⠼⠃⠚⠃⠋`
- 数字后紧跟 a–j 时加字母符 ⠰ 消歧（如 `2a` → `⠼⠃⠰⠁`），这是标准盲文约定
- 空格/标点/中文等非字母数字字符：**原样透传**（见已知局限）

## 设计取舍

- 只做一级盲文（逐字母），不做二级缩写——二级是整套缩写体系，不适合"小巧"工具。
- 解码时数字符后连续的 a–j 点字都转成数字，遇到空格/字母符/非 a–j 点字即结束数字模式。

## 已知局限

- 只支持英文一级盲文，无缩写、无中文盲文。
- 非 ASCII 字符编码时原样透传，解码时未知点字同样透传，不报错。
- 终端字体若缺盲文字形会显示方框——换个字体即可，这是显示问题不是编码问题。
